# 交互式 Horn-Schunck 光流可视化工具


这是一款基于 **Horn-Schunck** 算法的实时光流可视化工具。支持视频文件与摄像头输入，以彩色箭头直观展示运动方向与幅度，并提供手动调参与**自动调参**模式，让参数随运动强度自适应变化。

---

## ✨ 功能特点

- 📹 **输入源**：支持打开视频文件（AVI、MP4 等）或摄像头。
- 🧭 **Horn-Schunck 光流**：经典的全局平滑约束光流算法。
- 🎨 **可视化**：箭头颜色映射光流幅度（红=大，蓝=小）。
- 🎛️ **6 个实时滑动条**，分别控制：
  - 采样步长（箭头密度）
  - 平滑系数 α
  - 迭代次数
  - 幅度阈值（过滤微小运动）
  - 箭头缩放倍数
  - 颜色映射范围
- 🤖 **自动调参**：根据当前平均光流幅度动态调整所有参数。
- ⏯️ **播放/暂停** 和 **打开** 文件/摄像头，界面简洁。
- 💾 **输出视频**：将处理后的画面保存为 `output_video.avi`。

---

## 📦 依赖项

- **Windows** 操作系统（使用 `shobjidl.h` 实现文件对话框）
- **OpenCV 4.x**（C++ 库及头文件）
- **Visual Studio 2019/2022** 或任何支持 C++17 的编译器
- Windows SDK（COM 组件支持）

> 本项目使用了 `windows.h` 和 COM 组件，因此**仅支持 Windows**。

## 🚀 编译与运行

### 1. 克隆仓库
```bash
git clone https://github.com/treading-the-void/HornSchunck_optical_flow_viewer.git
cd HornSchunck_optical_flow_viewer
```

### 2. 配置 OpenCV
- 下载并安装 OpenCV。
- 设置环境变量指向 OpenCV 的构建目录

### 3. 打开解决方案
- 如果项目中包含 `.sln` 文件，直接双击打开。
- 否则，新建一个 **控制台应用程序** 项目，并将 `Proj_auto.cpp` 添加进来。
- 在项目属性中配置：
  - **包含目录**：`$(OPENCV_DIR)\include`
  - **库目录**：`$(OPENCV_DIR)\x64\vc15\lib`（根据你的 VS 版本调整）
  - **链接器输入**：`opencv_world4xx.lib`（Release）或 `opencv_world4xxd.lib`（Debug）

### 4. 编译运行
- 选择 **x64** 平台。
- 按 `F5` 运行。

> 生成的可执行文件位于 `x64\Debug\` 或 `x64\Release\` 下。

---

## 🎮 使用方法

1. 点击 **Open** → 在二级菜单中选择 **Camera** 或 **File**。
2. 点击 **Play/Pause** 控制视频播放。
3. 点击 **Auto On/Off** 切换自动调参模式。
4. 在 **Controls** 窗口中拖动滑动条，手动微调可视化效果。
5. 按 **ESC** 键退出程序。

主窗口显示：
- 当前帧图像及叠加的箭头。
- 帧序号、平均光流幅度、实时帧率（FPS）。

## 📊 参数详解

| 滑动条名称      | 范围   | 作用说明 |
|----------------|--------|----------|
| **Sample Step** | 0–50   | 采样网格的步长（像素）。步长越小，箭头越密集，细节更丰富。 |
| **Alpha x10**   | 0–100  | 平滑系数 α，实际值为 `滑动条值 / 10`。α 越大，光流场越平滑，抗噪性更强。 |
| **Iterations**  | 0–300  | Horn-Schunck 算法的迭代次数。次数越多，收敛越好，但耗时增加。 |
| **Mag Skip**    | 0–100  | 幅度阈值（百分比），小于该阈值的光流点不画箭头，用于过滤噪声。 |
| **Arrow Scale** | 0–40   | 箭头长度缩放倍数，让微小运动也能清晰可见。 |
| **color scl**   | 0–10   | 颜色映射的灵敏度，调整红–蓝渐变范围的宽窄。 |

---

## 🔧 自动调参逻辑

当 `Auto On` 开启时，程序会根据每一帧的 **平均光流幅度** 实时调整所有滑动条。经验公式旨在适应不同运动速度，使显示效果始终处于较优状态，无需手动干预。

---

## 📁 输出文件

处理后的视频（含箭头）会自动保存为 **`output_video.avi`**，采用 MJPEG 编码，帧率与输入源一致，保存在程序运行目录下。
